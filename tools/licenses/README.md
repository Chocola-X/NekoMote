# 打包依赖许可

GLAD 2.0.8 生成的代码标注 `(WTFPL OR CC0-1.0) AND Apache-2.0`；
打包同时保留上游 GLAD LICENSE 与下面完整许可，未选择本项目自己的许可。

- Apache-2.0：https://www.apache.org/licenses/LICENSE-2.0.txt
- CC0-1.0：Creative Commons，文本来自 SPDX 固定 v3.27.0 的
  https://github.com/spdx/license-list-data/blob/v3.27.0/text/CC0-1.0.txt

这些文件仅是依赖许可，由 `ci_package_licenses.py` 在打包时合并到 `THIRD_PARTY_NOTICES`，
项目自己的 AGPL-v3 单独放在 `LICENSE`。宽松许可证兼容性不免除声明保留义务。
