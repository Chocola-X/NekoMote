# 800 px/s 拖拽摆幅修正

端点混合及独立回摆策略已由 [实际物理惯性修正](drag-inertia-2026-10-20.md) 取代；本文保留当期结果，单参数端点不代表整体最大可见摆幅。

2026-10-20，基线 `0b29ebd`，Codex / GPT-6（精确变体未暴露）。
用户反馈 Chocola/casual-b-no-bell 经前两轮修改后双马尾、裙子反馈仍弱，要求
800 屏幕像素/秒达到最大摆幅，更慢按比例降低，并处理起停与反向。
本报告取代前两轮报告中的交互驱动策略；原素材绑定调查仍有效。

## 原因与修改

问题不是加速度阈值。旧实现将速度变为虚拟锚点偏移，匀速时锚点固定，
源质量点逐渐追上，持续反馈衰减；限幅进一步减小了摆动。增大这个偏移不能可靠满足
“指定速度持续保持指定摆幅”，因此删除了旧增益、作者单位椭圆限幅和虚拟锚点驱动。

显示位置仍立即跟随鼠标。固定 60 Hz tick 将合并位移分摊后，按输出像素计算：

```text
target = -movement / max(hypot(movement), 800/60)
velocity = (velocity + (target-position)*0.5)*0.5
position += velocity
```

`position` 径向限制为单位圆，抵达边界时移除向外的速度，避免累积和迟滞。
这是独立的交互姿态惯性，不冒充源模型的物理系数，也不对鼠标加速度作高频差分。
持续轴向 200/400/800/1600 px/s 分别对应 25%/50%/100%/100% 权重，斜向共享
同一幅度预算。缩放和镜像不改变屏幕速度门槛。零速度没有输入死区，仅在零输入时
将位置、速度均小于 0.0001 的数值尾部归零。

加载时，按输出 ParamId 收集素材启用的 Part/Layer 参数范围，取数值交集。
仅使用有效且含零的范围；不依赖头发、裙子等名称猜测绑定。
源 spring/chain/bend 正常积分，交互随后将各输出混合到其有符号端点：

```text
output = (1-abs(response))*source_output + abs(response)*authored_endpoint
```

spring 使用 X/Y，chain 使用根 X、纵向 Y、末段 X。未引用或无有效范围的输出保持源值，
零响应精确保留源结果；既有源值越界时不额外隐藏夹取。交互不修改源积分状态，
源动画造成的局部锚点运动保留，整体拖动行程从锚点输入排除。

恒定轴向满速从下一 tick 开始反馈，约 4 ticks（67 ms）到端点；停止下一个 tick
即开始回摆，反向也立即改变响应。典型合成轴向输入约半秒内回到零输入源结果，
不会因为移动了几千像素等待质量点慢慢追平。满速匀拖时保持最大偏转，起停有短暂回摆，
不是持续在端点之间自动振荡。素材关键帧非线性，线性的是参数混合权重，不是像素位移。

首个初始化 tick 不注入拖动；prepare 不消费输入；30/60 Hz 同轨迹一致。
显式定位、暂停恢复和 reset 清除交互待消费位移与惯性，错误路径恢复显示原点。
不增加开关、兼容实现或资产改动，OpenGL/Vulkan 共享同一求值路径。

## 真实型号验证

CPU 探针预热 240 ticks，关时间线，在相同静止姿态上隔离单链输出，排除整体平移。
按 NodeId/source 匹配活动非零透明度图元，采样固定 atlas 点；不比较自适应细分后的
不同顶点索引。下面为指定型号、fit scale 0.550131、800 px/s 匀拖第 60 tick，
同一 3×3 采样法的最大采样位移，单位为窗口像素：

| 部位 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 双马尾 | 3.58 | 61.82 |
| 裙摆 | 4.36 | 38.14 |

这些是几何采样点位移，不是每根发梢或最终无遮挡像素的位移。
另有 63 条 5×5 诊断：三个型号（上述型号及 Chocola/Vanilla wintermaid），
0、±200、±400、±800、±1600 px/s，及逐条根/末段/两者一起强制 ±30。
800 的稳态输出约 ±30，1600 保持上限，200/400 约 ±7.5/±15。
两个横向输出一起驱动没有抵消双马尾或裙摆；不需要修改解算器或素材。

普通可见 X11 player 窗口在两个后端验证指定型号，1920×1080、fit、60 FPS 预算，
应用内部 Controller 回调重放 800 px/s，固定诊断时间步，覆盖拖动及释放后回摆。
截图目视确认头发和裙摆形变增强、角色位置跟随；正常视线/待机仍运行。
截图读回影响帧率，因此这些窗口不作为性能或两后端逐像素一致性基准。
没有系统鼠标键盘注入，静音、`--no-save`，配置前后 SHA256 相同。
真实桌面插件的主观手感仍需用户确认。

素材集成 13 通过、2 跳过（源素材导入环境变量未设置、CJK 字体缺失）。

一项启停反向测试；更新速度、持续满幅、缩放镜像、追赶和生命周期用例。

每实例只有两个二维惯性状态，加载时预编译少量输出范围。固定 tick 增加少量标量运算，

`pointer_move + advance + prepare_frame` 普通 C++ 堆分配为零。
