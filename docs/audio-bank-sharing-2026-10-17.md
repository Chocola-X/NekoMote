# 语音解码数据共享：实现与验证

基线 `6dcd586`，任务来源：用户要求消除长期壁纸运行时的重复语音数据，保持功能、声音及画面质量。
该基线已经包含此前背景抽屉、四语言 UI 和首次启动默认背景改动；本次前后对照均含有这些改动。
本轮只修改音频数据所有权、调用者和对应验证，不修改 UI 业务、模型求值或渲染公式。

## 改动

原 ABI 和 player 在加载完成后复制一份 `candidate.audio_clips` 到宿主，再将另一份移交
`audio::Device`。宿主的副本用于设备销毁后重新启用声音，因此不能简单删除宿主引用。

现在将加载完成的 vector 移动到 `shared_ptr<const model::AudioBank>`，宿主和 Device
持有同一份只读 PCM/RMS。重建设备复用该 bank，不重新复制、压缩或降采样。Device
析构先停止并 join 工作线程，再释放 bank；宿主替换或先释放引用不会使旧设备借用悬空。
引用计数只出现在加载、设备创建/销毁和所有权交接处，不进入 `submit/snapshot` 帧路径。
公共 C ABI 不变，player、ABI 壁纸实例和音频诊断工具均已迁移，不保留旧构造接口。

`chocola/date-b` 的 19 份语音 float PCM + RMS 合计 **6,075,300 bytes（5.794 MiB）**，
声音开启且设备就绪时少保留一整份数据。不同角色的收益取决于语音长度；未加载声音时无此收益。
它不减少图形驱动/共享库映射，也不代表全部角色或跨实例之间已经共享声音。

## Release 内存对照

- 硬件：Xeon E5-1680 v4，8C/16T；RTX 3080 Ti，NVIDIA 580.82.09；KDE/X11。
- 原版：冻结的基线 Release/O3/LTO/Werror `nekomote_abi_host`；SHA256
  `d427a9659276ab3360af09940dbfad567500adf6a75f673f8743bdd4b20cd518`。
- 修改版：同构建配置；SHA256
  `f9d5479f8bf7fe76c0d612f87bc05defdb4131cebfcf0e9fcd6113d1b301d9f2`。
- 同一 assets 配置：`chocola/date-b`、BG_47、展开 UI、声音开启、seed 1、1920×1080。
  每次 1,500 个固定 1/60 秒步长；实际呈现速率不限制，不用它作为 60 FPS CPU/功耗基准。
- 使用独立 `/tmp` PipeWire/Pulse socket 和空输出，无硬件音频设备、无用户配置保存。
  GPU 测试串行。每个后端按原版→新版→新版→原版运行，均确认 `audio=ready` 并正常退出。
- 预热 300 帧后，每 250 ms 读取 `/proc/PID/smaps_rollup`；每次取中位数，再平均两次运行。
  GL 每次 3–4 个样本，Vulkan 每次 26–27 个样本，因此 GL 的短采样和进程波动需保留解释空间。
  没有截图读回、profiler、功耗或 CPU 性能采样。

| 后端 | RSS 原版 → 新版（MiB） | RSS 减少 | PSS 原版 → 新版（MiB） | 私有驻留减少 |
| --- | --- | --- | --- | --- |
| OpenGL | 140.22 → 136.46 | 3.76 MiB | 69.88 → 66.20 | 3.68 MiB |
| Vulkan | 155.72 → 149.90 | 5.82 MiB | 72.21 → 66.41 | 5.81 MiB |

RSS 同时受驱动映射、分配器保留页和进程波动影响，不能承诺每个进程恰好下降 5.794 MiB。
本组 Vulkan 匿名驻留减少 5.791 MiB，与去掉一份语音数据吻合；GL 匿名驻留减少 3.682 MiB。
这些是共享 ABI 的独立诊断进程结果，不是用户当前 `plasmashell` 的实测改善，不能直接从
Plasma 整体 RSS 中减去该数。主要收益为内存，未宣称 CPU/GPU 或功耗下降。

## 验证

- Release player、C ABI host 和 Plasma QML 插件构建通过，Werror 开启。
- 新增设备契约测试：4 个用例、29 条断言通过，覆盖无副本移动、宿主先释放、设备重复重建、
  新旧 bank 重叠寿命及 null/无效 PCM/RMS/采样率拒绝。使用不可达音频服务器，无播放命令。
- ABI 合成边界：7 个用例、88 条断言通过。上述两项同时通过 ASan/UBSan/LeakSanitizer；
  初次沙箱内 LeakSanitizer 受 ptrace 限制失败，随后在沙箱外重新执行通过。
- 既有 `[audio],[controller],[ui],[session]` 单元测试：35 个用例、6,284 条断言通过。
- 私有空输出的真实 WAV 探针：播放前暂停、恢复、播放、停止和重播通过，实际时钟驱动
  RMS 最大值 0.399143。销毁设备后从保留 bank 创建新设备，释放宿主 bank 引用，再次完整
  执行同组播放检查通过，RMS 最大值相同。未通过用户扬声器发声。
- 另一执行者只读复核所有权和候选失败边界，未发现新增阻塞项；`git diff --check` 通过。

内存对照和播放脚本/日志保存在本地忽略目录 `build/evidence/audio-bank-20261017/`；
`memory-abba.json` 保存每次二进制 hash、命令和全部样本，`playback.csv` 及
`playback.csv.recreated.csv` 保存两次播放状态与 RMS。
