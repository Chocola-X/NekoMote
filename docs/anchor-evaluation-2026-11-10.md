# 物理锚点按需求值：实现与动态回归

日期：2026-11-10。基线 `ff74172`；执行 Agent：Codex，模型家族 GPT-6，具体变体未暴露。
对应 [独立报告](potential-optimizations-analysis-2026-11-09.md) 的物理前几何求值建议。

## 判断与实现

建议成立，但报告所称 advance 几何开销可减少40%～50%不是现成的测量结果。
原 `step_tick` 为读取物理锚点执行完整 geometry.evaluate，之后 prepare_frame 再用物理
输出求完整几何。两个输入状态不同，不能合并或复用上一帧锚点。
本次保留这两个时序，只把第一遍的世界变换/曲面准备缩到导出定位器及其祖先。

- 编译时为**全部静态分支**中的导出定位器建立祖先位图，不依赖当前活动分支。
  分支切换、时间跳跃、暂停恢复、模型更换无需维护跨帧 dirty 状态。
- 每遍仍对**全部选中节点**解析当前参数/关键帧、检查不支持语义，并计算组合姿态。
  这些工作在跳过点之前，保持原先错误码、节点和时序。world/curve 闭包以外的组合节点
  仍会验证；组合的 parent.transform、child_sync 和祖先 pose.patch 不依赖世界坐标。
- 世界矩阵、曲面控制点、形状继承、组合链及排除附件的公式与 Float32/double 保存顺序
  完全沿用原实现。只跳过闭包外的这些工作，以及本遍无用途的图元/遮罩/排序整理。
- 新 `GeometryEvaluation::Locators` 只提供定位器及依赖节点观察，不能 build_frame。
  最终 Frame 求值完整重建节点状态；拖动时临时物理原点与输出原点的切换保持原契约。

195款编译场景含330～925节点；锚点世界变换闭包61～91节点，逐型号等权平均占14.96%。
7款基准的闭包占比为13.53%～18.59%。这不等于整遍只执行15%的工作，因为姿态与组合
校验仍扫描所有节点。本机每个编译场景额外位图及 vector 头约88～160字节（不含分配器
元数据），实例新增求值范围枚举，逐节点 State 没有增加字段，不新增逐帧分配。

原候选曾保守地将全部组合节点及祖先也纳入世界闭包，平均覆盖77.51%节点。核查真实
依赖后确认没有必要：组合校验已在跳过点前完成。收窄后重新执行最终动态和图像对照；
没有采用只检查定位器局部坐标或删掉完整错误检查的捷径。独立只读执行者复核了闭包、
组合错误传播和 partial→full 生命周期，建议的连续组合负例与嵌套锚点逐位检查已补齐。

## 性能

Xeon E5-1680 v4 / RTX3080Ti、NVIDIA580.82.09、GCC15.2.1、Release/O3/LTO/Werror。
7型号×待机/拖动视线共14组，固定种子12345与1/60秒，CPU0，120步预热、600步采样，
三轮前后/后前/前后。按每场景三轮中位数，再等权汇总变化率；负值代表耗时减少。

| Session advance | -30.40% | -30.86% | -29.21% | -33.40% |
| Session prepare | -2.86% | -3.52% | -0.79% | -2.96% |
| Session 总耗时 | **-8.24%** | **-8.77%** | **-6.36%** | **-7.59%** |

14组总均值与P50全部改善，P50改善范围7.67%～11.01%。独立完整geometry.build仍有
P50平均+1.18%、均值+1.77%的小幅代价；总P95/P99的单组最差分别+7.61%/+6.61%。
未锁频、未独占桌面，尾部存在环境波动；没有把这些局部回退隐去。结合总CPU和总体
分位数收益，按用户允许整体改善时接受局部轻微回退的标准保留。

全部测量帧指纹相同，140份抽样帧逐字段字节相同；预热后所测Session与独立几何路径
普通C++ new为0。不能据此推定UI、驱动或整个壁纸进程零分配。

首版的advance P50已减少30.05%，但prepare增加5.78%，总P50只减少1.34%，部分场景总P50
增加1.94%。重新编译原版复查后，反汇编确认候选将曲面多项式内联进逐顶点循环，
build_frame机器码从6506增至7297字节；原版保留独立调用。通过局部noinline包装保留
共享计算边界后为6678字节，不改公式或累加。最终结果基于该版本重新跑三轮与全部回归。
这是GCC15/LTO下实测的编译布局影响，不能推为其他平台的普遍规律，也没有单独证实
寄存器溢出或指令缓存各自贡献。原始首版数据和补丁均保留，没有掩盖这次局部倒退。

范围是 Session advance+prepare 的 CPU 耗时，包含动画、物理与几何，不是整个桌面进程、
纯GPU时间或功耗。GPU绘制协议/资源/渲染器未改，未测长期RSS/显存/功耗，也未安装到用户
桌面。没有将节点跳过比例转换成整机收益。完整原始数据、逐场景不利变化和复现方法见
[证据目录](validation/anchor-evaluation-2026-11-10/README.md)。
