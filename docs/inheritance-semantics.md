## 公式与生命周期

`W` 为曲面之前的世界仿射变换，`S` 为保留的自身曲面链，`P` 为排除的父曲面链，挂接点 `q=S(W(0))`：

```text
vertex = S(W(v)) + P(q) - q
```

先解析子节点局部位置和自身曲面，再计算自身原点随父曲面的位移。整片顶点叠加相同位移，保留自身变形、阻断父曲面逐顶点拉伸。旧候选在分组原点计算位移，遗漏子节点局部位置。没有按型号/节点名或常数补偿。

每次evaluate在world_patch就绪后计算 `attachment_offset`，祖先已经完成求值；参数、原点、缩放和组合变化均重建缓存。顶点只读取缓存；不新增稳态堆分配或递归。无排除链保持旧浮点运算。position-sync1仍只弯曲直接子原点，sync8保留曲面传播；自身combine帮助层保持组合顺序。
