# 曲面祖先链优化与对照验证

基线 `0dc14663dc8812a328d9a9d2f185528e5dad8d4f`。按用户要求，先实施此前分析中
不改变曲面公式的低风险候选；沿用用户允许综合成本下降、局部轻微退步的判断标准。
原始数据、环境、哈希与复现入口见 [验证目录](validation/curve-chain-2026-11-08/README.md)。

## 实现与正确性边界

`deform_curves` 原来对每个点逐一访问 `curve_parent`，遇到非曲面节点只继续回溯。
前轮实际输入计数为每顶点检查约 9～12 个节点、执行约 2 次 warp；该计数用于选择候选，
没有被当成 CPU 耗时降幅。

现在每个 State 缓存 `next_curve`，指向原链上最近的实际曲面祖先。
节点仍按祖先先于后代的次序求值；完成当帧 pose、组合与继承选择后，从已经求值的
`curve_parent` 读取其曲面状态或 `next_curve`。顶点进入链时只判断一次自身是否有曲面，
随后按缓存直接执行 warp。每次 evaluate 清空并重建状态，不跨帧猜测失效条件。

原 `curve_parent`、`excluded_curve` 与附件链仍保留。没有改变形状排除、位置同步、
组合曲面的边界、曲面执行次序、控制点、Bernstein 公式、double 累加次序或 Float32 保存点。
失败求值仍不发布帧，下次求值重新构建状态；没有新增分配、并行、图形资源或公共 API。

本机 x86_64 的 `sizeof(State)` 从 416 增至 424 字节，代表场景的 403～480 个节点
约增加 3.2～3.8 KiB/GeometryInstance；Playback 的各实例分别计费。

## Release 性能

Intel Xeon E5-1680 v4、GCC 15.2.1，Release/O3/LTO/Werror。
7 型号 × 待机/拖动与视线输入，共 14 组；固定种子 12345、步长 1/60 秒，
每组预热 120 帧、采样 600 帧，CPU 0，基线/候选交替三轮。
每组每项指标先取三轮中位数，再对 14 组变化率等权汇总；不按用户桌面使用时长加权。
采样期间不运行构建、其他基准或测试；诊断 hash/帧保存不在计时区间。

| CPU 范围 | 均值变化 | P50 变化 | P95 变化 | P99 变化 |
| --- | --- | --- | --- | --- |
| Session advance + prepare | -7.34% | -7.60% | -5.53% | +3.87% |
| Session prepare | -9.44% | -9.66% | -7.89% | -0.62% |
| 独立 Geometry evaluate | +0.70% | +0.20% | +4.62% | +12.62% |
| 独立 Geometry build | -12.97% | -13.03% | -11.84% | -8.35% |

14 组总均值和 P50 均下降，总 P50 降幅为 2.66%～13.92%。
独立节点求值增加少量缓存构建工作，几何构建减少重复链遍历；两项独立计时不能直接
拼接为 Session 的函数级独占占比。advance P50 平均变化 +0.01%。

局部尾部没有全部改善：date-a 动态组总 P99 为 587→711µs（+21.08%，约 124µs），
Chocola wintermaid 动态为 680→782µs（+15.01%）。没有锁频或独占桌面，无法把这些
尾部变化全部归因于实现或调度噪声；按稳定的均值/P50 与整体 P95 收益权衡保留，
不声称所有场景和分位数都变快。

该测试覆盖会话与几何 CPU，不含 UI、声音设备线程、GPU、合成器、swap/present；
没有测量功耗或新增显存占用，不能把 7.60% 直接当成整个壁纸进程或桌面的 CPU 降幅。

## 验证

- Release/LTO/Werror 完整构建通过。
- 新增一个合成测试：两层不满足交换律的曲面之间及叶子前各插入四个刚性节点，
  反复启用/关闭两层曲面，以独立解析坐标检查点采样与实际帧顶点，并覆盖输出原点/缩放。
- 7 型号 × 2 输入的每组 600 帧字段 fingerprint，基线/候选三轮全部一致；
  每 60 帧抽样，共 140 份帧字段二进制一致。没有重生成既有参考数据。
- 探针覆盖的预热后 Session 与独立几何路径，普通 C++ new 均为零；不扩展到驱动或整个应用。
- CPU CTest：261 通过、3 跳过。跳过为源 JSON 导入、私有 Pulse 和 CJK 字体条件缺失。
- 私有 Xvfb/Mesa/Lavapipe 的 GL、GLES、Vulkan 与 Python ABI 四组 GPU 回归通过；
  这是既有 GPU 回归，并非新增真实桌面或 14 组基准的 GPU 图像对照。
- 独立 Debug ASan/UBSan、启用泄漏检查与 UBSan 出错终止，`[runtime]` 分组
  88 用例、28,372 断言通过；该结果不参与 Release 性能汇总。

没有安装插件、修改桌面、注入系统输入或执行网络发布。
全 195 型号动态、ARM64、真实桌面呈现/功耗和长期运行仍未覆盖。
