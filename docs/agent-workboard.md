## 成本与质量原则

- GLM作为主要实现者：契约明确的C++/Qt、构建、客观测试、扫描和原始证据。准确新求值公式先取参照证据，再独立验收；额度不降低门槛。
- Gemini承担实际视觉观察与测点、局部诊断UI。不从截图存在、CPU成功或代表家族推断MATCH；不可见区域明确未核。
- Codex优先语义、线程/生命周期/ABI及最终整合。便宜关键修复直接完成；长实现、采样和整理交GLM。能力边界依据实际工具和交付，不使用未经验证的模型排名。
- 摘要≤一页：任务/base/文件、PASS/FAIL/Skipped与分母、关键hash、复现和未知。长日志、大图放新build目录，不覆盖旧证据。缺证据退回补齐。
- 来源字段参考与执行WebGL分别标记；诊断读回不得计入正式播放/性能；加载成功、实现完成、视觉通过和独立验收分别记录。
- 不改原素材/资产绕过缺口，不注入系统输入，不安装/改桌面配置。核心支持范围、UI/渐变/reset、声音失败、长时多屏及正式安装仍需验收。
