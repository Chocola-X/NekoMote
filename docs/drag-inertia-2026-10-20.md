# 恢复明显的拖拽惯性与回摆

2026-10-20，修改基线 `3ea4ec3`，效果对照基线为最早修复之前的 `8e850c0`。
Codex / GPT-6（精确变体未暴露）。用户要求恢复早期版本明显的双马尾、裙摆摆动，
保留快速响应，特别要求对比最早版本而非仅比较上一轮修复。
本报告替代 C23 的端点混合策略；素材绑定调查继续有效。

## 差异与实现

原版把累计屏幕位置送给物理锚点。高速拖动能使参数超出素材 ±30 的范围，
几何夹取在端点，松手后需要先从越界区返回，才显现变化；随后有较大的反向回摆。
C23 虽能到单个参数的端点，但直接把输出混合成共同姿态，没有让拖动真正激励源链。
其独立小振荡器的反向峰值仅约 3.35，约半秒就消失，不能替代原来的往返运动。
此外，源链横向拖动自然产生纵向伸展、抬升及 bend；只驱动横向端点也丢失了这部分耦合。
“到参数端点”不等于整个模型可见形变达到最大。

这次删除端点混合、范围交集缓存和独立姿态振荡器，直接激励已有粒子状态。
显示位置跟随鼠标；物理锚点继续排除累计屏幕行程，保留源动画的局部运动。
固定 60 Hz tick 分摊 pending 位移后，计算有界屏幕速度及其变化：

```text
u = movement / max(length(movement), 800/60)
du = u - previous_u
particle_velocity += -36*du - stiffness*distance*u
```

`distance` 为 spring 的 64、chain 的 80 作者单位；它们与 36 均为交互策略参数，
不冒充素材的物理系数。持续力按已有恢复刚度缩放，零刚度不持续增加拖拽驱动力。
800 px/s 及以上为同一满激励，以下输入线性降低，斜向共用单位圆预算。
速度变化有界，因此启停、反向与合并事件不会产生无限大的加速度脉冲。

只限制交互增加的分轴速度，范围为 ±72 作者单位/tick。原有运动已在范围外时，
不剪掉源速度，仍允许交互减小其速度。初始化 tick 不加激励；以后在现有 next 状态
副本上先加速度扰动，再执行原 spring/chain/bend 解算，成功后统一提交。
没有第二套物理链，也不将 source external_displacement 改为其他含义。

松手时速度变化立即给出反向惯性激励，随后由每条链的原有刚度、摩擦、长度、重力及
bend 继续衰减，发根与发梢保留不同相位。输出不再被交互策略钳成共同端点。
最终形变仍遵循现有几何参数范围；自然解算的瞬时输出可以超过该范围。
线性的是输入激励，实际摆动幅度、相位和像素位移取决于非线性物理及素材。

prepare 不消费输入；追赶先分摊位移再归一化；显式定位、暂停/恢复重置待消费速度，
保留允许保留的物理状态；reset 清除物理与输入状态。失败不提交粒子状态或上次速度，
并恢复显示原点。未改低层源 spring/chain/bend 公式、素材、GPU 或桌面适配器。

## 与最早版本对照

诊断在当前程序中复刻 `8e850c0` 的原 Controller `set_origin` 入口，关闭新拖拽输入；
源求值零拖拽路径保持原行为。候选使用 `drag_origin`。旧入口只在忽略的诊断工具中，
正式程序不保留旧模式或兼容开关。

CPU 几何探针关闭时间线、预热 240 ticks；800 px/s 横拖 60 ticks，再停留 360 ticks。
对每条后发/裙摆链同时替换根、纵向、末段三个输出，其他参数使用静止实例，排除整体平移。
按 NodeId/source 匹配活动非零透明度图元，固定 5×5 atlas 点，避免自适应细分的顶点索引误差。

不是所有部件都移动该距离，也不是最终无遮挡像素统计。

候选均为 2，约由 0.33 秒缩至 0.033 秒。候选约 0.1 秒发根已反向，
约 0.5 秒两段均可摆到另一侧端点，之后继续衰减；保留了明显往返，不再是短暂回正。
这不是所有输入的全局延迟上限，也不保证全程没有几何端点停留。

普通可见 X11 player 使用 1920×1080、fit、60 FPS 预算、seed=1、静音、no-save，
以内部 Controller 回调重放相同轨迹。原入口 GL、新入口 GL 和 Vulkan 各记录 11 帧，
从拖动前覆盖至松手后六秒。诊断副本禁用真实 cursor move 回调，避免无关指针移动混入。
目视确认：起拖反馈及时、满速有明显形变、松手后出现不同相位的双向摆动并逐渐停止。
对照图只作整体水平平移对齐，没有局部扭曲。
截图读回使这些运行低于目标帧率，不作为性能或两后端逐像素一致性基准。
没有系统输入注入、桌面配置修改或资产写入，用户配置前后 SHA256 相同。
