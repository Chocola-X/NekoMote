## 源码复核与优先级

| 建议 | 核对与处置 |
| --- | --- |
| 物理锚点按需求值 | 有实际潜力；前后两次输入不同，“完全相同的重复求值”不成立。子集必须保留组合、排除附件、参数分支和错误事务；需独立依赖闭包设计，不能直接删一次 evaluate。本轮暂缓大范围改造。 |
| 两趟 + float + SSE2 | 运算数漏算双坐标，单点两趟不是 48→20；现有代码已部分向量化。降精度违反既有 Float32/double 保存契约，不采用 60%～70% 承诺或隐式 fast-math。 |
| 关键帧游标 | 几何按变量采样会反向、跳转，不能假设单调；尝试只复用仍包含当前时间的区间，否则原 upper_bound。动画事件通常很少，先不为事件引入循环/重启状态。 |
| GPU 变形 | CPU 边界继续保持；报告依赖尚未证明的两趟收益，不能据此宣布现状开销已极低。 |
| 最终合成 scissor | 真实存在全屏合成；优先进行小范围可撤回试验，见阶段一。 |
| GL UI 合批 | 多次上传属实；全局按材质重排破坏透明绘制顺序，矩形的颜色/半径又是逐 draw uniform。正确合批需新的逐顶点数据与有序命令设计，菜单关闭时收益有限，暂缓。 |
| int16 PCM | 可省存储，但 int16 不是任意来源 FLAC 的无损表示；还需迁移声音设备/重采样与口型输入，不能称零复杂度。本地音频仅数 MiB，优先级低于稳态 CPU。 |
| 旧背景重解码 | 确有问题；当前新建 renderer 保证失败时旧背景继续有效。简单在旧 renderer 上传不能重复 ID，失败可能保留半初始化资源；需要事务式纹理转移/共享和后台切换回归，暂缓。 |
| 直接加载编译快照 | 涉及资产 schema、编译器和迁移，收益是加载边界而非稳态；缺少切换耗时归因，不列为低成本。 |
| Peer 共享纹理 | Peer 仅共享程序属实，但不同角色的图集不是相同资源；共享只有确实相同的资源才获益，并需设备/上下文生命周期约束。暂缓通用池。 |
| Vulkan 分配器/staging 环 | 加载期分配和上传等待属实，稳态没有每帧纹理上传。缺少加载期 profile，不新增分配器依赖或同步状态机。 |
| GLES 去 POT | 前轮真实图像已失败；不因 API 支持 NPOT 重做相同改动，见经验汇总。 |

## 阶段一：最终合成 scissor，撤回

只在既有顶点验证中增加保守 bounds，GL/GLES/Vulkan 仅裁剪 ProtectedStraight 最终合成；
原目标 clear、遮罩、颜色混合和逐点几何均不改。未引用点/遮罩源也纳入 bounds，避免漏绘。

Xeon E5-1680 v4、RTX 3080 Ti / NVIDIA 580.82.09、GCC 15.2.1，Release/O3/LTO/Werror。
3840×2160、固定 60Hz 步长、种子 12345，3 型号 × 待机/拖动，每组 120 帧预热、300 样本，
CPU0，三轮交替。没有锁频或独占桌面，计时不含 PNG 读回；构建与采样不并行。
每组先取三轮中位数，再等权汇总变化率；complete 含等本帧 GPU 完成，不含桌面呈现。

| API | prepare 均值 | 会话至提交 CPU 均值 | 等完成均值 | 等完成 P50 |
| --- | --- | --- | --- | --- |
| GL | +8.19% | +1.81% | +3.17% | +4.51% |
| GLES | +8.34% | +1.92% | -0.58% | -0.58% |
| Vulkan | +9.64% | +0.76% | +2.87% | +4.99% |

18 对最终 PNG 二进制一致；私有 Xvfb/Lavapipe Vulkan 回归包含新增的分数边界、翻转、
屏外、空帧 clear/preserve 检查通过。没有逐帧像素读回参与性能测量。
由于未见综合收益，GL/VK 代码及专项测试全部撤回，补丁作为证据保存，不留正式开关。
不能把可见角色面积直接换算为填充或功耗节省，也不能据此否定更紧 bounds 的后续方案。

原始数据、试验探针、二进制哈希、撤回补丁与图像哈希在
[验证目录](validation/optimization-2026-11-09/)。真实资产和衍生图像不入库。

## 阶段二：节点关键帧区间复用

为每个节点保存 upper_bound 索引。只有当前时间仍满足已缓存区间的左右边界时才复用，
跨关键帧、回退或跳转仍调用原二分查找；不假设变量随时间单调，不改变插值数学。
缓存不放在每次清零的 State 中，实例构造时一次分配，约增加 8 字节/节点（本组约 3～4 KiB）。

同一 runtime_probe、7 型号 × 待机/拖动与视线，120 帧预热、600 样本、三轮交替，CPU0。
固定步长、种子与前轮一致，未运行并行构建/测试。结果为三轮中位数的 14 组等权变化率：

| CPU 范围 | 均值 | P50 | P95 | P99 |
| --- | --- | --- | --- | --- |
| Session advance + prepare | -0.36% | -0.41% | -0.28% | -0.49% |
| 独立 Geometry evaluate | -0.73% | -0.51% | -1.11% | -2.08% |

14 组总 P50 均下降，范围 0.05%～1.10%，但绝对收益很小，不能称大幅提速或推广为
其他 CPU/编译器的保证。实现约 20 行变化、无数学和语义变化，按本机稳定小收益保留。
普通 C++ new 均为零，全部 600 帧字段 fingerprint 三轮一致，140 份抽样帧字节一致。
新增非单调采样与新实例对照，覆盖首帧前失活、精确边界、插值区间、末帧后和重新激活。
Release/LTO/Werror 与 CPU/GPU 回归结果保存在验证目录。
