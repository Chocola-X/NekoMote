## 已验证的范围

`SpringState` 由实例拥有，保存相对当前锚点的位置和速度；`advance_spring` 只推进一个 60 Hz 作者步，不读 JSON、不找字符串、不访问图形或宿主。锚点位移和 SDK 外部位移先改变相对粒子位置，然后计算重力/弹簧，再将速度乘 `(1-friction)`，最后更新位置。外部位移不是加速度。首个锚点初始化只定位保存的快照，不推进积分，也不施加第一步外部位移。

输入、位置和速度使用作者单位，Y 向下。元数据 scale 影响场景位移到作者单位的换算；不依赖显示缩放、charaProfile.height 或 pixelMarker。gravity/spring/保存快照进入数值计算前按源 Float32 转换。内部 double 求值与冻结最终标量轨迹在 1e−5 单位内一致；尚未声称每个内部状态的位模式一致。

`spring_output` 将 SDK amplitude 乘到粒子位置，再减去保存的竖直 ofs，然后施加各轴 scale_x/scale_y 和反正切映射。斜率 `0.045160394715788144` 来自原 Math.atan 的单位外部位移输入，在四个型号、不同 metadata scale、SDK amplitude、axis scale 和更改人物高度/标记的隔离实验中复核。输出乘 `80/pi`，整对绝对分量都小于 0.01 时归零。两分量各约 0.0075、模长超过 0.01 的实验仍归零，排除按向量长度判定的候选。

SDK amplitude=0 不关闭积分，而且胸部保留 ofs，静止时 UD=-18.189874649；amplitude=2 静止时约 +18.1906。不能把这些数值当作模型常量写进场景，也不能用零 amplitude 替代 enabled=false。

12 组原 SDK 冻结轨迹覆盖原/0.5 弹簧、0.125/0.5 摩擦、重力、外部位移开关、死区与单/双分量、amplitude=0/2；见 `tests/fixtures/spring_reference.json`。测试有 535 条数值断言，容差 1e−5；null 表示当时未采样该分量，不伪造参考值。来源 hash、原始元数据 hash 和每个 PSB fixture 修改均保留。

## 已验证的弯曲输出内核

`advance_bend` 接受已映射的 root_x/vertical/tip_x 标量和实例独立的 BendState，推进一个 60 Hz 作者步；它不读取模型 JSON、不求锚点，不承担粒子积分。严格在 `abs(vertical)>28` 时 gain 每步增加 1/32（上限 1），否则减少 1/32（下限 0）。通过修改轴 scale 并选取相邻 Float32 值，原 GetVariable 恰好输出 28 的实验没有激励，排除 >= 的候选。

phase 增加 speed*gain，周期使用源 Float32 `2*pi`。周期内将 double 增量直接传给 sin，然后保存 Float32；越过周期时先把新相位转成 Float32 再取余，负相位保留负余数。25、-9 的初相位和跨周期持续激励验证该顺序。偏移 `sin(phase)*volume*gain` 从 root_x 减去、向 tip_x 加上；SDK amplitude 已在粒子输出中生效，不再次乘偏移。最后三分量绝对值均小于 double 0.01 时全归零；相邻 Float32 volume 的抵消位移实验核实死区边界。

17 组、331 步数值证据冻结在 `tests/fixtures/bend_reference.json`：普通跳跃、单/双分量位移、幅度 2、volume 4、正负初相位、多周期激励、精确 28 阈值和 0.01 死区，共 1324 条输出/相位断言。输出容差 1e−5，保存后 phase 与观测 sin 参数转 Float32 逐步相同。输入是原 Math.atan 对应的物理标量与不受弯曲影响的 UD；它是输出阶段数值验证，不是完整粒子求值证据。

另做四组真实前发隔离截图（24/48 步、正负 50 位移、幅度 2/volume 4），fixture 设零 stretch/gravity/初速度、初位置 64/112、ofs=0，禁用其它物理。原生自行累计已知位移并映射 UD，调用新弯曲内核，经正常 GeometryInstance/render_gl 出图；没有输入原参数轨迹或顶点。四图均通过 2/255 门槛，alpha 与黑/白合成 RGB 最大 1/255，几何最大 0.0000821711px，48 步并列图已目视核实。见 [图像/基准证据](validation/p6-bend-images.json)。

Debug/Release 56 项、ASan/UBSan 55 核心入口通过；预热后的 1000 步无普通 C++ new，独立状态/快照恢复一致。Release+LTO，120 步预热，9 批各一百万步，常量未弯曲输入 {0.01,35,-0.01}，最小/中位/最大 12.112/12.449/12.9657 ns/step；仅弯曲输出，不含粒子、场景或 GPU，不能代表完整引擎帧时间或功耗。

剩余：头发伸长/第二粒子约束的数学结构已有隔离证据，但大位移 60 步的状态/临时向量 Float32 舍入仍有约 5e−5 的标量残差；失败候选保留在忽略的 evidence，未接入正式运行时。接下来闭合积分和实际锚点绑定，将所有物理接入共同作者时钟，核实未修改 PSB 的完整动作画面。

## 两节链条积分内核

独立 `advance_chain` 保存两粒子的 Float32 位置/速度，坐标是初始锚点的作者空间；锚点位移独立累计为 Float32，不逐步重定位粒子。第一步保留保存速度、跳过重力/摩擦/外力积分，但投影过长的末端。之后锚点移动包含原生锚点差及作者单位外部位移。第一节只有超过 length[0] 才产生伸长弹簧，方向归一化向量存 Float32，长度和力计算保留 double 中间量。

根粒子先积分，末端对保存后的根位置施加最大长度投影。`v_bound` 的含义是去除法向速度的系数，1 去掉法向分量、2 反射，并非保存整个速度的比例；自然使用 X/Y 不等摩擦的 Fraise 配件轨迹与两组倾斜末端实验验证该区别。速度的重力加法和摩擦乘积保留临时 double，保存 Float32 速度；位置使用临时乘积，而非已经舍入的速度。输出位移也在保存位置之前相对当前 Float32 rest 点计算再存 Float32。每一个舍入边界都有控制轨迹/存储观察支撑，不读原核心源码。

已验证 vertical_effect=0：根/末端各自水平 scale_x；根的 UD offset 在 amplitude 内，加法方向与 Spring offset 不同。输出随后进入既有 Bend 内核和三分量死区。输入系数/快照须在编译边界验证，内核不读取 JSON、图形或宿主，不分配内存。资产 schema 4 中旧保留字段名称 velocity_retention 尚需在正式绑定时改名并升级 schema，不将其解释为速度保留。

## 原生链条绑定与模型放置

`PhysicsProgram` 编译 vertical_effect=0 的 Hair/Parts 链条，绑定输出和导出锚点，复制粒子/弯曲快照。Hair、Parts、Bust 有独立幅度及作者单位位移输入；输出与弹簧一起预分配。所有锚点先采样、全部下一状态先计算，任一失败不提交任一控制器或 tick，输出为空。新增混合弹簧/链条失败、重试、独立状态、未知 rest/z/vertical_effect/bend、输出重叠与 200 步绑定/求值/构帧零普通 C++ new 回归。

原网页实验确认：命名的锚点不存在时，启用链条仍以固定原点响应外力；控制器并未被禁用。其输出即使没有 drawable 使用，也由场景在加载时声明 ParamId。导出标记自身的零局部原点空显示帧仍可提供锚点，未选中的 motion 资源分支则是另一状态；对非零空标记及不明继承仍拒绝。现有锚点没有活动分支时明确失败，这个分支切换边界的更一般行为仍待观察。

移动模型首次数值对照出现约 4.0054e−5 的 UD 差异。双精度参数时间/属性插值和 identity 网格缓存边界候选均未闭合，已撤出。父控制器存储观察显示同一已知输入、原网页 y=400 与 y=0 的锚点差分别为 10.529296875 和 10.529327392578125；对应 UD=-19.318660736 与 -19.318696976。模型放置参加 Float32 父矩阵累积，不能等价成绘制最后加位移。原生 `set_origin` 明确这个模型空间契约，实例独立、改变后求值失效，不与输出投影耦合。

五组 24 步实际绑定对照（缺失锚点启用/禁用、缺失锚点下模型移动、空标记/正常标记下移动）全部通过 1e−5，最大 8.761882782e−6；几何通过 0.001px，五张图片全部通过 2/255，正常移动并列图已目视检查。原生只使用输入事件和自身锚点/粒子，不输入参考参数或顶点。完整启用 8 个控制器的未修改 PSB 静止与转头 24 步数值/图像通过；跳跃和待机差分分别保留最大 0.000253677、0.000280708 的标量失败，待机差分图片还有一个 RGB 3/255 像素超标。跳跃图片虽然通过，也不替代标量验收。详见 [绑定与原始失败](validation/p6-chain-binding.json)。
