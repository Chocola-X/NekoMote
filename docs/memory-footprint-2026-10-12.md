# C14：内存占用测量与优化

基线 `7e458fb`，Codex / GPT-6（精确变体未暴露）。用户观察到初始约 190 MB、
连续切换后约 300 MB。本机复现支持这一观察：默认 glibc 下，重复切换后的 RSS
为 248–322 MiB；优化后同条件为 180–201 MiB。声音开启时由 262–286 MiB
降至 192–211 MiB。保留 OpenGL/Vulkan、原始纹理和求值公式，不改写成 C。

## 条件与结果

AMD Ryzen 7 5800H、RTX 3060 Laptop、NVIDIA 575.64.03、KDE/X11，GCC 15.1.1，
Release/O3/LTO/WERROR，libpng 1.6.50。以下全部为 MiB（1024² bytes）。

高层 C ABI 诊断宿主使用 1920×1080 输出、完整共享 UI、BG_07A、seed=1、禁止保存配置。
初始角色来自保持不变的本地配置 `fraise/casual-a`，预热 120 帧。
之后按 Fraise maid-b、Coconut hawaii-a、Vanilla date-a、Milk teenage、Cinnamon maid-b、
Chocola date-a 顺序重复三轮，共 18 次异步切换；每轮等待加载与渐变结束，
末尾再推进 120 帧。GL 使用隐藏 EGL 窗口，VK 使用 ABI 宿主的离屏目标；
不能将其资源数字直接当作 Plasma 整个进程的预算。

外部观察器约每 20 ms 采样 `/proc/PID/status`，阶段边界记录 `smaps_rollup`、
`smaps`、`mallinfo2`、`malloc_info`。性能采样不附加截图、验证层、ASan 或 tcmalloc；
GPU 工作串行。静音各做两次独立进程测量，声音各做一次。

| 后端/声音 | 原初始 RSS | 新初始 RSS | 原切换后 RSS | 新切换后 RSS | 原采样峰值 | 新采样峰值 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| GL / 静音 | 190–245 | 169 | 267–322 | 195–201 | 321–386 | 233–239 |
| VK / 静音 | 191–220 | 153 | 248–280 | 180 | 328–358 | 245 |
| GL / 声音 | 194 | 172 | 286 | 211 | 344 | 251 |
| VK / 声音 | 195 | 156 | 262 | 192 | 342 | 257 |

相同旧二进制的两次 GL 进程相差约 55 MiB，涉及分配器/驱动的映射与缓存；
不能用单次百分比承诺其他机器的精确占用。新 GL 静音切换后 PSS 为 140–146 MiB，
匿名页约 52–55 MiB；新 VK 为 PSS 104 MiB、匿名页约 51 MiB。
RSS 还包含字体、共享库及驱动文件映射，不等于引擎存活堆对象大小。

另外直接测量 `build/release/bin/nekomote_player`：Chocola date-a、BG_07A、UI 开启、
1920×1080、静音、30 FPS、120 帧预热后 300 帧，禁止保存配置。
GL 稳态 RSS 167.6 MiB / 峰值 172.3 MiB，VK 稳态 157.8 / 峰值 162.0。
VK 使用测量入口的 IMMEDIATE 呈现；这不是普通 FIFO/Plasma 的性能认证。
约 29.7 FPS 的实测播放通过，未用这些单次结果宣称 CPU 提速。

## 改动与原因

- 模型 JSON 按 part/layer/frame 转换并释放记录，避免完整 DOM 与强类型树同时存活。
  保留结构校验与字段状态，明确拒绝重复对象键；schema 6 不变。
- 编译会话后立即释放源模型/会话树，再创建实例、PCM 和图像缓冲。
- PNG 从 libpng 直接解码到最终 RGBA vector，去掉旧解码器的整图临时缓冲和复制。
  保留编码色值、straight alpha、行方向；不应用 gamma/ICC 转换。
- 中文字体文件使用只读映射，由私有 RAII 所有者管理，避免把约 19 MiB TTC
  全量复制到匿名堆。字形缓存及后端上传协议不变。
- 几何预留按各可能图块的实际长宽比网格取上界，替代每部件的大方形上界。
  同时覆盖零密度继承曲线的最小九顶点网格；求值和细分结果不变。
- ABI 用已经上传的背景尺寸恢复模型切换后的背景，不为查询尺寸重新解码 PNG。
  player 在成功提交候选后转移同一背景 GPU 所有者，避免重复上传。
  清除背景时释放对应 GPU 资源；PCM 通过移动交给声音服务。
- 渐变结束先销毁借用 program 的实例，再释放 program。删除旧字体 vector 和
  不再使用的 stb PNG 解码实现，没有添加旧模式或兼容层。

glibc 会保留已经释放的 arena 页。旧 GL 首次切换稳定后 `mallinfo2` 记录
约 90 MiB arena 空闲块，因此稳态上涨不全部是存活对象泄漏。
独立 tcmalloc 归因采样记录字体约 18.6 MB、几何实例约 7.6 MB；
该采样替换了分配器，仅用于定位，未混入上表。
正式实现没有全局 allocator 调参、`malloc_trim` 或每次切换强制回收。

## 正确性与边界

- 195 个现有模型：完整 DOM 转换与新加载器的强类型数据逐字段重新序列化比较，全部一致。
  324 张现有 PNG：新解码与原 vendored stb 解码逐像素、逐尺寸相同。
- Release CPU CTest 184/184；GL 13 用例/233 断言，VK 7 用例/198 断言。
  VK 独立 GPU 检查使用 core+同步验证层。最终 Release 全 CTest 187/187 亦通过，
  其默认 VK 层状态不作为上述强制验证的证据。
- ASan/UBSan：资产、图片、容量 15 用例/386 断言；Controller/应用生命周期
  36 用例/5972 断言，泄漏检测开启。Plasma 隔离四项通过；第一次层未配置失败保留，
  配置工作区验证层后通过。GL/VK 真实窗口 owned callbacks 检查通过，
  该窗口检查未启用 VK 验证层，也未注入系统输入。
- 同 seed/固定步长的完整角色、背景和 UI 图，各后端与 C13 PNG 字节一致。
  实际查看本轮 UI 和 WebGL 对照图；复用 C13 同日冻结的真实 WebGL 初态，
  RGB 最大差 1/255、alpha 差零、黑/白底合成差零。没有重新改动参考仓库。

按 PID 的 `nvidia-smi` 显存约一秒采样，GL 记录峰值由 161 降至 143 MiB，
VK 两次均为 109 MiB；这些是粗采样最大值，不能证明真实瞬时峰值或同幅度收益。
显存改善有限：4096×2048 RGBA 图集仍需 32 MiB，再加背景、输出/遮罩和驱动资源。
未使用压缩、降采样或有损素材处理。

剩余占用包括驱动映射、运行中资源和分配器保留页。模型数据压紧、跨实例共享及纹理格式
优化仍需具体收益/质量证据，不以 C 风格指针或手工释放替代所有权设计。
本轮未做 miku 安装、跨设备比较、长期压力、195 全动态或全部求值语义认证。

原始证据位于 ignored `build/evidence/memory-20261012/`；条件、二进制、输入和日志 hash
见 [机器记录](validation/memory-results.json)。构建新增系统 libpng 1.6 开发依赖，
分发容器配方同步；参考行为为 [libpng 官方手册](https://www.libpng.org/pub/png/libpng-manual.txt)。
