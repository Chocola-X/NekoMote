# 共享壁纸 FPS 显示

2026-11-17，Codex。基于 `5d5a45d` 的工作区更改，未安装真实桌面插件。

## 行为和实现

设置增加“帧数显示 / 开启帧数显示”，默认关闭。开启后显示位置选项：左上、右上、
左下、右下，默认左上。开关、位置按现有面板偏好规则保存，遵守 `--no-save`。
英文、简体中文、繁体中文和日文标签均已补齐并在初始化时准备字形。

应用层的 `FrameRate` 按单调墙钟统计绘制调用间隔，约每 250ms 更新显示值。
共享 UI 使用固定长度缓冲区输出一位小数和 `FPS`，整数格式化避免小数点受 locale
影响。文字使用与“重设角色位置”相同的粉色（`#c2527f`）、白色描边，固定在输出角落，
先于控制图标和菜单绘制，不参与鼠标命中。描边与填色在 OpenGL 中可合并为一个文字 batch。

普通播放器及共享壁纸 C ABI 均接入同一计数/绘制实现，OpenGL / Vulkan 复用 UI
绘制协议。未修改各适配器、公共 C ABI、模型求值或 GPU 绘制公式。

这里的数值是共享 UI 的绘制调用节奏，不是设定的帧率上限、模型物理 tick 或屏幕最终
呈现速率。首次开启、超过一秒的绘制间断及共享宿主暂停/输出状态变化后重新采样，
初始为 `0.0 FPS`。不为刷新数字额外唤醒暂停或不可见的壁纸；停止绘制时画面上的
读数也不会继续刷新。重复上报相同宿主状态不会重置计数。

配置字段与使用说明见 [配置说明](configuration.md)。

每帧一个文字 batch。此范围不含驱动 malloc、其他线程、整个应用或 Vulkan 分配认证。

`chocola/date-a`、960×540、seed=1、固定 120 步截图：四角开启与关闭的差异均限于

截图和下表性能数据采自初版浅粉色。按用户反馈更换为 `reset_text` 颜色后，重新构建
Debug 播放器及单元测试，FPS 相关 3 项、81 条断言通过；未重复全部 GPU 或性能测量。

## 开关开销对照

Xeon E5-1680 v4 / RTX 3080 Ti，NVIDIA 580.82.09，KDE X11。
Release/O3/LTO，OpenGL，`chocola/date-a`，1920×1080，60 FPS，seed=1，fit、
平色背景、静音、菜单关闭。每场预热 120 帧、采样 300 帧，开关各三轮，表为各分位数
的三轮中位数。CPU 时间包含求值、构帧、UI 与 GL 提交，不能当作 GPU 完成时间。

| 关闭 | 1.268 / 2.112 / 2.374 | 59.676 |
| 开启，左下角 | 1.143 / 1.895 / 2.261 | 59.670 |
