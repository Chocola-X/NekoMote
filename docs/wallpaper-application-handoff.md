# G31：共享壁纸应用层与player迁移

状态：G31/G32 已有源码交付。本页保留原设计/验收要求，不作为当前待实施顺序；当前用户优先 Plasma 效果，见 [任务交接](agent-next-handoff.md)与 [显示补修](plasma-display-fix.md)。

来源：用户要求先将player的UI/控制切换下沉，并保留后续Vulkan适配能力。调查基线 `39762b6`，接手时记录实际base；本文件是实施契约，不是已实现状态。GLM负责G31A→G31B，Codex复核边界/线程，Gemini检查受控截图。G32 ABI/Plasma迁移在G31之后，本轮不实现Vulkan。

## 1. 模块边界

| 模块 | 归属与输出 | 不应进入的实现 |
| --- | --- | --- |
| application | Controller、资产目录、配置语义、会话/声音策略、CPU加载候选、角色/背景选择与渐变状态、fit/拖拽/reset等模型交互；输出普通值/资源ID/图层与绘制数据 | GLFW/Qt、GL/Vulkan调用或句柄、shader、UI布局、具体设备实现 |
| ui | 共享角色/背景/设置面板、UI局部开合状态、布局/命中、事件消费、字体度量、后端无关UI绘制数据；读Controller状态并发语义请求 | 独立角色切换状态机、资产扫描、配置副本、GL/Vulkan调用或native纹理ID |
| render_gl | 模型/背景/UI协议的GL绘制、字体/图标纹理上传、shader、裁剪/混合、GPU资源管理 | 模型选择/渐变计时/配置策略、UI命中、application/UI业务状态依赖 |
| player | 窗口/上下文、输出尺寸/DPI、事件采集、宿主暂停/关闭、CLI与截图/测量诊断；组合共享模块 | 正式资产扫描、配置规则、UI面板代码、切换/渐变/失败恢复状态机 |

公共绘制数据表达当前需要的顶点/索引、语义资源ID、图层顺序/alpha、裁剪和混合，不包含GLenum、GLuint、Vk对象、GLSL或驱动函数指针。明确作者/输出坐标、颜色和alpha约定；NDC、viewport/Y翻转、native裁剪/同步转换留在后端，不把GL坐标或枚举写进业务数据。UI先生成绘制数据，GPU执行由后端完成；资源ID由设备内映射解析，不能以整数类型包装GL纹理名宣称已解耦。字体度量/像素准备与GPU上传分开，加载或显式内容变更时完成，不在稳态帧解码/上传字形。

优先复用已有RenderFrame与简单值类型，按实际UI需求补最小协议；不创建空render_vk、后端工厂、万能平台接口或同时重写模型shader。未来Vulkan复用同一Controller/UI与CPU数据，native输出目标/设备/同步及上传/绘制/释放由Vulkan后端和对应宿主接入处理，不假设GL FBO可跨API直接复用。绘制数据借用寿命和后端资源就绪/回收边界显式记录，不能以GL立即调用习惯假定GPU工作已经完成。

## 2. 所有权、时间与事务

- Controller拥有当前/旧/候选CPU会话及业务切换状态；每壁纸实例独立。目录/配置是唯一业务来源，UI只保留面板状态。只读资产可按实际需求共享，不用全局Controller或共享可变会话。
- GPU对象属于共享绘制实现，壳只提供允许的上下文/输出目标。G31阶段player可暂留薄资源绑定桥接，但不能在桥接里决定选中角色、回滚、渐变时长或配置保存。不得把现有CharacterHolder（CPU/GPU/音频混合所有权）整体搬入Controller。
- CPU候选准备不阻塞稳态帧；GPU上传在有效上下文线程的显式加载边界完成。CPU成功不等于可提交：GPU准备成功后才确认切换，失败保留当前角色/背景/配置和有效输出。旧资源保持到渐变完成或明确取消；过时/失败候选释放，不保留隐藏fallback。重复请求的Busy/取消策略明确记录，不新增无界任务队列。
- 同一串行求值线程拥有Controller/UI/会话状态；加载worker只产出拥有数据的候选，不借用窗口、UI对象或活跃实例。GUI事件/异步结果经有界队列或同步快照交接。frame/catalog/string视图有效期明确，后台任务不能越过其Owner销毁；关闭时先停止新请求并回收worker，再销毁业务/服务与GPU资源，各释放遵循线程约束。
- 区分用户暂停、应用策略暂停与宿主不可用；统一计算有效暂停。模型、背景、角色渐变共享每次最多250ms的接受时间，暂停/失败不推进渐变，恢复首delta为0；不用切换开始后的全部墙钟时间计算进度。UI面板自己的开合动画与模型时钟分开，面板打开是否暂停模型由共享策略决定。
- 壳仅采集事件和基础坐标/DPI信息，不做UI命中或模型命中。共享路由先让UI消费，再把剩余事件交Controller；鼠标拖拽/fit/reset语义归共享层。明确逻辑/物理像素、原点、DPI/输出变更及输入能力；沿用模型ABI中心framebuffer像素/Y向下约定时，UI的布局坐标转换只做一次，不重复镜像，不通过读取GL viewport猜布局。
- application负责配置schema/校验/默认值/保存时机；壳只提供存储位置或桥接，assetsDir选择页仍可属于宿主。切换成功后保存，失败不覆盖有效选择；窗口尺寸/DPI等输出事实不伪装成用户配置。无保存诊断模式须显式支持。
- 音频策略和命令归application，设备实现复用src/audio。现有audio依赖application命令，禁止application再反向链接audio造成环；在共享组合边界通过服务契约连接。G31保留已有player音频能力与服务桥接，不复制PCM/Pulse/worker，也不把正式声音补全算作已验收。

## 3. G31A：Controller/控制切换 + player迁移

改动范围：`include/nekomote/application/`、`src/application/`、`apps/player/main.cpp`和目录/配置代码、相关CMake与测试；必要的后端无关公共值类型可调整。禁止本阶段修改Plasma/QML、正式C ABI、模型求值公式或外部素材。

1. 从`asset_catalog.*`迁移目录扫描/分组/展示名、配置加载保存与校验，强类型公共数据不泄漏JSON库。application的Controller可以依赖asset_io/文件系统；已有Session求值路径保持不做I/O。
2. 从main迁移角色/背景选择、CPU异步加载候选、切换/渐变/reset、配置提交和模型交互状态。资源上传结果通过明确就绪/失败契约反馈；保持音频和图形服务边界。小契约说明随首个实现提交，不要求先创建大量空接口。
3. **同阶段迁移player**，仍使用现有UI作为调用者；UI按钮发Controller请求，主循环读取共享状态/帧。移除已迁移的目录/配置源文件、命名空间及旧状态机，不留同步/异步双套正式业务路径；诊断入口也调用Controller。迁移当前有效CLI、截图/输入验证工具和测试；单素材诊断与目录播放是显式用途，不保留被替代业务接口或自动兼容回退。

验收：Release/WERROR与无窗口核心构建；合成CPU测试到达真实切换、GPU准备失败反馈、重复请求、暂停/恢复预算、失败配置不提交、reset及卸载候选分支。受控player输入验证加载期间旧角色继续推进、成功/失败切换、背景/声音/fit保持；输入只用自身回调。保留初态/idle120的同条件WebGL证据和阶段前后player固定图，记录差异原因，不能用新native图冒充参照。

## 4. G31B：UI/GL执行拆分 + player迁移

改动范围：`include/nekomote/ui/`、`src/ui/`、`src/render_gl/`的UI绘制实现、`apps/player/ui.*`/main/图标字体绑定、相关构建与测试；必要时补绘制协议。Controller只做实际需求调整，不让application依赖ui/render_gl。

1. 提取面板构建、布局、命中、滚动/开合、事件消费与UI绘制数据；从Controller取目录/设置/加载状态。把`ui.cpp`中的GL shader、纹理上传/释放/绘制放到render_gl；FontAtlas中CPU度量与GPU atlas所有权拆开。布局/hit-test测试不需要GL上下文。
2. 同阶段迁移player使用共享UI及GL执行，删除旧ui实现/GL上传片段与旧构建目标。窗口回调只转发输入；鼠标进入面板不触发模型反应，未被UI消费的事件仍到达共享模型处理。
3. 稳态只复用缓冲与绘制数据，resize/DPI/字体内容变更有明确失效条件；上下文释放只销毁GPU资源，重建后保留可保留的Controller/UI状态。记录每个GPU资源的设备/上下文归属，不共享不同设备的native句柄。

验收：无显示CPU布局/命中/路由测试；真实GL句柄上的UI绘制、裁剪/透明合成、resize/DPI/释放重建；受控面板点击后选择/配置/渐变正确。角色/背景/设置面板与阶段前固定截图对照；初态/idle120模型继续与WebGL一致，Gemini目视检查遮罩、字体、面板边缘与UI隔离，未看图不宣布视觉通过。

两阶段都运行影响范围的测试，修改帧路径时分别测Controller/UI/GL预热后的分配与帧耗时，不混截图/加载，不以核心零分配代替应用零分配。冻结base、diff/工具/二进制/素材hash、argv、日志、图与数值报告；失败/未跑/性能变化单列。每阶段验证后commit，真实Agent/Model/Context；报告≤一页，raw存新build目录。

## 5. 退出与后续

G31完成意味着player使用共享实现、application/ui无窗口和图形API依赖、公共数据不依赖GL句柄，且旧player业务/UI实现删除；**不等于Plasma已迁移或Vulkan已实现**。源码搜索和CMake依赖检查作为验收的一部分，不能只看目录是否创建。

G32再扩当前C ABI的壁纸实例/目录/配置/输入/UI绘制和设备生命周期，复用同一共享模块；薄C宿主验证完整功能而不复制声音/线程服务。随后Plasma只经ABI调用，删除scanCharacters/scanBackgrounds、QML控制面板及重复配置/切换策略，保留assetsDir入口、错误提示和宿主职责。迁移前明确线程/借用数据/输出目标/销毁契约；真实桌面/长期/多屏仍独立验收。现有Plasma GUI直接修改背景共享资源的问题必须在该阶段消除，不把旧壳作为正确所有权范本。

G30正式声音背景等余项按共享边界继续；C8求值反例独立推进，不因未解语义阻塞G31，也不在重构中放宽不支持资产或像素门槛。
